# Local book files

This folder is for full book text that Kitsamba Writes Africa is legally allowed to host.

## File naming

Use the same slug used in `books/library.json` and `authors.html`.

Examples:

- `things-fall-apart.txt`
- `no-longer-at-ease.txt`
- `arrow-of-god.txt`
- `purple-hibiscus.txt`
- `half-of-a-yellow-sun.txt`
- `americanah.txt`
- `dream-count.txt`
- `weep-not-child.txt`
- `a-grain-of-wheat.txt`
- `petals-of-blood.txt`
- `kintu.txt`
- `manchester-happened.txt`
- `the-first-woman.txt`
- `waiting.txt`
- `whispers-from-vera.txt`
- `promises.txt`
- `tropical-fish.txt`

## Chapter formatting

For books you own or have permission to publish, format the text like this:

```text
# Chapter 1

First paragraph...

More text...

# Chapter 2

Next chapter...
```

The website reader will detect headings beginning with `# ` as chapter starts. If there are no chapter headings, it will automatically split long text into readable pages.

## Rights

Only add complete text when the work is yours, public domain, openly licensed for this use, or you have permission from the copyright holder. The website can still show the local metadata/summary when no full text file is present.
