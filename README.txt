KITSAMBA WRITES AFRICA — NEW PAGE FILES

Included:
- plays.html — upcoming plays: UNPREDICTABLE DESTINY and LAST MEET
- poems.html — upcoming poems: BETWEEN LIFE AND GOODBYE, THE SMALLEST LIGHT, THE LAST SPEAR OF ORENS
- stakeholders.html — supporter/partner information and a Donate / Become a Supporter button
- index-additions.html — snippets for the existing index.html: navigation links and Behind the Stories photo gallery

DESIGN
The new pages use the same dark background, warm gold accents, Playfair Display headings, DM Sans body text, rounded cards, and responsive layout.

IMPORTANT
The Donate button currently opens contact.html with a donation/support subject. It does not collect payments; payment details or a payment provider must be configured first.

INSTALL
Upload plays.html, poems.html, and stakeholders.html into the root of the same GitHub repository as index.html. Then copy the snippets from index-additions.html into the existing index.html. Do not replace your entire index.html with the snippets.
The images are externally hosted by Unsplash and require an internet connection.
